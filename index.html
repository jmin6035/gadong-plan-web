CGL 분기 가동계획

판매계획·자가재계획·배선일정 엑셀을 올리면 도금 1·2CGL 일별 가동계획(M/C 최소 → 선생산 최소 → 평준화)을 계산해 엑셀·간트로 내려받습니다.

🔒 파일은 서버로 전송되지 않습니다. 모든 계산은 이 브라우저 안에서만 합니다. · 조회용 대시보드 →

1입력 파일

    저장해 둔 계산 결과 열기(.json) — 파일 없이 결과만 다시 보기

    2계획 조건

    첫날 강종 (전월 말 라인 상태)

    정기수리(S/D)

    고급: 시간손실·생산속도·계산 시간 제한

    시간손실(분)

    생산속도(t/hr) — 라인×강종×부서, 실적 달성속도

    3입력 확인

    ① 입력 파일에서 엑셀 두 개(가동_판매자가재, 배선일정분석)를 올리면 여기에 수요 요약이 나오고 계산 시작 버튼이 켜집니다. 계획 조건(②)은 기본값(v30) 그대로 두면 됩니다.

      PC에서 약 10~15분, 휴대폰은 더 걸립니다. 계산 중에는 이 탭을 닫거나 화면을 끄지 마세요.

      계산 중

        결과

        월별 간트

        이미지를 누르면 원본 크기로 열립니다. 굵은 파란 숫자 = 자가재 포함일, 노란색 = M/C·재가동, 회색 = 정기수리.

        M/C·S/D 일정과 이유

        전월 선생산

        4실적 반영 재계획

        위 결과를 기준 계획으로 두고, 기준일까지의 실적(설비고장·불량 반영)으로 남은 기간을 다시 계산합니다. 지연·결품을 먼저 막고, 그다음 M/C 최소, 같은 조건이면 기존 계획과 가까운 일정을 고릅니다.

        방법 1 — 실적 엑셀 (MES 연동 시 이 형식)

        방법 2 — 간단 입력 (엑셀 없이: 기존 계획대로 생산했다고 보고 아래 사건만 반영)

        남은 기간이 짧을수록 빨리 끝납니다. 결과는 위 “결과”에 표시되고 엑셀·대시보드도 재계획 기준으로 바뀝니다.
