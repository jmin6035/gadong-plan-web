CGL 롤링 계획 계획 담당자용

판매계획·자가재계획·배선일정 엑셀을 올리면 도금 1·2CGL 일별 가동계획(M/C 최소 → 선생산 최소 → 평준화)을 계산해 엑셀·간트로 내려받습니다.

🔒 파일은 서버로 전송되지 않습니다. 모든 계산은 이 브라우저 안에서만 합니다. · 실적 분석 → · 가동 현황 →

1입력 파일

    저장해 둔 계산 결과 열기(.json) — 파일 없이 결과만 다시 보기

    2계획 조건

    첫날 강종 (전월 말 라인 상태)

    정기수리(S/D)

    고급: 시간손실·생산속도·계산 시간 제한

    시간손실(분)

    생산속도(t/hr) — 라인×강종×부서, 실적 달성속도

    3입력 확인

    ① 에서 가동_판매자가재 엑셀을 올리면 여기에 수요 요약이 나오고 계산 시작 버튼이 켜집니다. 계획 조건(②)은 기본값(v30) 그대로 두면 됩니다.

      PC에서 약 2~4분, 휴대폰은 더 걸립니다. 계산 중에는 이 탭을 닫거나 화면을 끄지 마세요.

      계산 중

        결과

        모두에게 게시 — 어느 폰·PC에서든 대시보드에서 같은 결과를 보게 합니다

        결과를 암호로 잠가 사이트에 올립니다. 암호를 아는 사람만 대시보드에서 열 수 있고, 암호화·해제는 각자 브라우저 안에서만 합니다. 암호는 6자 이상.

        GitHub에 바로 게시(관리자) — 토큰 필요

        토큰 만들기: GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token. Repository access = Only select repositories → gadong-plan-web, Permissions → Repository → Contents: Read and write. 토큰은 저장하지 않으며 이 창을 닫으면 사라집니다.

        상세 결과 보기(요약·간트·전환 이유·선생산) — 전체 화면은 대시보드에서

        월별 간트

        이미지를 누르면 원본 크기로 열립니다. 굵은 파란 숫자 = 자가재 포함일, 노란색 = M/C·재가동, 회색 = 정기수리.

        M/C·S/D 일정과 이유

        전월 선생산

        4실적 반영 재계획

        위 결과를 기준 계획으로 두고, 기준일까지의 실적(설비고장·불량 반영)으로 남은 기간을 다시 계산합니다. 지연·결품을 먼저 막고, 그다음 M/C 최소, 같은 조건이면 기존 계획과 가까운 일정을 고릅니다.

        방법 1 — 실적 엑셀 (이 양식 또는 MES 실적 쿼리 엑셀 그대로 — 자동 인식, 기준일은 실적이 다 들어온 날까지로 맞춤)

        방법 2 — 간단 입력 (엑셀 없이: 기존 계획대로 생산했다고 보고 아래 사건만 반영)

        재계획은 시간이 걸려도 최적임이 증명될 때까지 계산합니다. 보통 수 분이면 끝나지만, 실적이 계획과 크게 어긋나면(결품·대량 지연) 수십 분 이상 걸릴 수 있습니다. 계산 중에는 이 탭을 닫거나 PC를 절전시키지 마세요(휴대폰보다 PC 권장). 결과는 위 “결과”에 표시되고 엑셀·대시보드도 재계획 기준으로 바뀝니다.
