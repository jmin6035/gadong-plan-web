월별 가동계획

숫자 단위: 톤. 라인 행 = 당일 라인 생산 합계, 그룹 행 = 당일 판매 그룹별 물량, 가동시간 = 작업 + 정지(색상교체·청소 등) 시간. 과거 일자 = MES 실적(사내 PC 가 매일 계획과 같은 그룹으로 분류 — 계획재·건재 주문재·건재수출·가전수출·가전내수·수요개발). 건재 주문재 = 판매계획의 '주문재'(컬러건재 국내 고객 주문 생산, 계획재 아님). 휴지(h) = 그날 휴지 시간, 칸 색 = 휴지 종류(범례, 여러 개면 가장 긴 것 — 마우스를 올리면 전부), 블록 = 종일 정지(종류·기간·시간), 옅은 회색 = 가동 없음. 칸 선택 시 당일 품목 표시.

기준일 라인 현황

그룹별 월 생산량 4분기 · 생산일 기준 · 막대 = 10·11·12월 생산 + 미편성(빗금)

상세: 미편성 목록 · 일별 품목

미편성 — 판매계획에 있지만 만들 수 있는 라인이 그 달 한도(MES 월차)·가동시간을 다 써서 일정에 못 넣은 물량. 이대로면 그 달 판매계획 미달

일별 품목과 배치 사유는 가동 캘린더에서 날짜 선택 시 확인.

라인별 편성 / MES 월차 한도

편성 = 일정에 넣은 물량(지난 날은 실적), 한도 = MES 월차(라인별 월 생산 목표 톤). "남음" = 한도까지 덜 채운 양 — 배정할 물량 없음: 이 라인에서 만들 수 있는 판매계획을 다 넣었음, 가동시간 부족: 수리·정지로 시간이 모자라 이 라인 품목 일부가 미편성.
